Bench

  1. 01research infrastructure~1K COMMITS

    Backtest, replay and live call the same process_bar(). Divergence is impossible by construction, not merely unlikely.

    • walk-forward, frozen out-of-sample, FDR correction

  2. 02agent orchestration~700 COMMITS

    A private control plane for multi-agent workflows. The hard part is surviving a crash mid-call, not calling a model.

    • transactional queue: atomic claim, idempotent enqueue, bounded retry
    • budget ceiling checked before a billable call
    • append-only hash-chained journal, checkpoint + replay
    • fail-safe autonomy: an unlisted transition stops and asks
