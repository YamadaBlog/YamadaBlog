cat ~/principles.md

  1. Measure, then believe. Every result carries its test: out-of-sample, cost stress, multiple-testing correction.
  2. One code path. If backtest and production can diverge, they will. Make it impossible, not unlikely.
  3. Seal the evidence. Frozen test sets, hashed datasets, append-only decision logs.
  4. Kill ideas fast. A documented “no” is worth more than an unexamined “maybe”.
  5. Ship fortresses, not tents. Fewer features — tested, documented, built to outlast their author.
