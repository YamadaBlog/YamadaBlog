Systems that have to be right, not just run.

Research infrastructure, agent orchestration, reverse engineering and security research. Most of the work is private; this report is the index to it. Figures are drawn from measured data. Where a quantity is unavailable it is reported as unavailable rather than estimated.1

§ 1 — PositionThe instrument, and what it is pointed at.

MethodEvery figure in this report is recomputed nightly from the GitHub API by a stdlib-Python renderer. No hosted widget is involved.

Software that merely runs is a low bar. The work collected here is the other kind: research platforms where a single look-ahead bug silently invalidates months of results, orchestration that has to survive being interrupted mid-call, and assessment work where the only acceptable answer to an unproven claim is to write down that it is unproven.

The through-line is not a technology. It is a refusal — to let a measurement drift away from the thing it claims to measure. Backtest, replay and live execution call one code path, so divergence is impossible by construction rather than merely unlikely. A test set is opened once and is then spent. A service-level report returns unavailable instead of computing a number from zero observations.
